# Glossaire métier maître

| Terme | Définition de référence |
|---|---|
| Domaine métier | Ensemble cohérent de règles, données et responsabilités métier. |
| Capacité | Aptitude durable que YDIASE doit posséder ; elle peut traverser plusieurs produits et services. |
| Formation | Parcours d’apprentissage offert par un établissement, défini dans une période de validité. |
| Programme | Structure officielle d’une formation : objectifs, modules, règles et qualifications visées. |
| Compétence | Capacité démontrable mobilisable dans un contexte. |
| Connaissance | Savoir ou concept maîtrisable ; elle n’implique pas seule une capacité démontrable. |
| Métier | Ensemble d’activités professionnelles, compétences et contextes économiques associés. |
| Opportunité | Élément actionnable pour une personne : emploi, stage, bourse, formation, concours ou événement. |
| Offre observée | Annonce ou signal collecté ; elle ne représente pas à elle seule le marché du travail. |
| Source autoritative | Système désigné comme référence opérationnelle pour un type de donnée donné. |
| Assertion | Fait attribué à une source, avec provenance, validité et confiance. |
