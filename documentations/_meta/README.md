# Métadonnées documentaires YDIASE

Ce dossier contient uniquement la mécanique de la documentation canonique : schémas, ontologie, maturité, index générés et règles de validation.

Il ne constitue pas une seconde documentation. Toute connaissance produit, métier, système, contrat, décision, confiance ou exploitation doit avoir une source canonique hors de `_meta`.

## Principe

**Source → Référence → Vue générée → Preuve.**

Les catalogues, matrices et graphes calculables doivent être générés à partir des sources canoniques et ne doivent pas devenir des sources concurrentes.
