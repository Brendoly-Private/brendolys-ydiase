# Registres de gouvernance

| Registre | Objet minimal |
|---|---|
| Décisions | ID, contexte, décision, alternatives, conséquences, date de revue, statut. |
| Exigences | ID, source, capacité, règle, phase, vérification, statut. |
| Risques | ID, probabilité, impact, domaine, propriétaire, mitigation, déclencheur, statut. |
| Hypothèses | ID, énoncé, méthode de validation, seuil, échéance, statut. |
| Sources | ID, producteur, territoire, domaine, méthode, droits, fiabilité, actualisation. |
| Systèmes autoritatifs | Type de donnée, propriétaire, système, copies permises, consommateurs, synchronisation. |

Les registres sont des sources de pilotage ; ils ne remplacent pas la provenance des assertions individuelles.
