# Règles métier — Identité et profils

Statut : `DOMAIN-BASELINE-CANDIDATE`

| ID | Règle |
|---|---|
| IDP-R001 | Une personne possède une référence interne durable distincte de ses identifiants d'accès et externes. |
| IDP-R002 | Un identifiant externe peut changer ou disparaître sans modifier automatiquement l'identité métier. |
| IDP-R003 | Une fusion de personnes exige un niveau de preuve défini et une trace d'arbitrage. |
| IDP-R004 | Une fusion contestable doit rester séparable tant que la consolidation n'est pas irréversible selon politique approuvée. |
| IDP-R005 | Une déclaration personnelle reste distincte d'une assertion vérifiée. |
| IDP-R006 | Une preuve conserve sa provenance et la méthode ayant produit son statut. |
| IDP-R007 | Le profil courant ne remplace pas l'historique lorsqu'une valeur historique légitime existe. |
| IDP-R008 | Toute donnée temporelle conserve uniquement la précision réellement connue. |
| IDP-R009 | Les références Education, Skills, Careers et autres restent sous l'autorité de leurs domaines. |
| IDP-R010 | Une préférence de visibilité ne constitue pas un consentement de traitement. |
| IDP-R011 | Une donnée de profil n'est exposée à un consommateur que selon sa finalité et ses droits. |
| IDP-R012 | La fermeture IAM et la fin de conservation métier sont deux opérations distinctes. |
| IDP-R013 | Une correction ne supprime pas silencieusement la provenance de l'état corrigé lorsque sa conservation est légitime. |
| IDP-R014 | Les contradictions entre assertions sont conservées jusqu'à résolution documentée. |
| IDP-R015 | Aucun moteur IA ne peut créer un fait biographique autoritatif sans source ou action métier gouvernée. |
| IDP-R016 | Les règles liées à l'âge, au territoire ou au statut légal sont évaluées dans le contexte temporel et national applicable. |
| IDP-R017 | Une projection ou vue de profil ne devient jamais une nouvelle source autoritative. |
| IDP-R018 | Les migrations doivent préserver identité, sens, temporalité et provenance nécessaires. |
| IDP-R019 | Les données personnelles inutiles à une finalité ne doivent pas être copiées dans un autre domaine. |
| IDP-R020 | Les anciennes versions sémantiques doivent rester interprétables ou disposer d'une transformation documentée. |
