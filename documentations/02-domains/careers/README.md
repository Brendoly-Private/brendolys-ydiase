# Domaine 05 — Métiers et carrières

Statut : `DOMAIN-BASELINE-CANDIDATE`

## Mission

Le domaine Métiers et carrières sépare :
- la vérité de référence sur les métiers, exigences et relations de carrière ;
- les trajectoires et transitions construites pour un contexte ou un sujet ;
- les simulations, qui restent des résultats hypothétiques et jamais des faits source.

## Frontières physiques actuelles

- `YD-MS-CAR-001 — Occupation & Career Graph` : `AUTH / C2`.
- `YD-MS-CAR-002 — Career Path & Transition` : `MIXED / C2`, portant physiquement les responsabilités logiques CAR-002 et CAR-003.

`CAR-004 — Career Simulation` reste un service logique documenté. Aucune nouvelle frontière physique n'est créée à cette phase.

## Doctrine

- CAR-001 ne possède pas les Skills canoniques ;
- signaux marché/LAB sont des evidence, pas une mutation automatique du référentiel métier ;
- trajectoire, transition et simulation conservent les versions de leurs entrées ;
- une trajectoire/reconversion est un résultat contextualisé, pas une vérité sur l'avenir d'une personne ;
- aucune IA ne transforme une prédiction en fait autoritatif ;
- données personnelles minimisées ;
- hypothèses, incertitudes et explications accompagnent les résultats.
