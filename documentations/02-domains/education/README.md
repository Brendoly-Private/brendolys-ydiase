# Domaine 03 — Éducation et institutions

Statut : `DOMAIN-BASELINE-CANDIDATE`

## Mission

Le domaine Éducation fournit les vérités structurées et versionnées relatives aux institutions, programmes, curricula/modules et cadres de qualification utilisés par BRENDOLYS YDIASE.

Il ne possède ni l'historique éducatif d'une personne, ni ses compétences, ni les décisions Privacy, ni les configurations pays.

## Frontières

- `EDU-001 / YD-MS-EDU-001` — Institution Catalog
- `EDU-002 / YD-MS-EDU-002` — Program Catalog
- `EDU-003 / YD-MS-EDU-003` — Curriculum & Module
- `EDU-004 / YD-MS-EDU-004` — Qualification Framework

Les quatre frontières restent physiquement autonomes dans la cible actuelle.

## Doctrine

- données publiées versionnées ;
- provenance et validation traçables ;
- aucune hypothèse éducative codée en dur comme vérité continentale ;
- contexte pays explicite lorsque la sémantique en dépend ;
- pas de base partagée entre frontières ;
- pas de transaction distribuée Program/Curriculum ;
- une projection ou un moteur de recherche ne devient jamais autorité du catalogue.
