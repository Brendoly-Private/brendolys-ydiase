# Composants de plateforme autonomes YDIASE

> **Rôle du document**
> Présente et indexe les composants de plateforme documentés de BRENDOLYS YDIASE.
> **Usage développement :** information de navigation et de contexte.

Ce dossier documente les frontières `YD-PLT-*` qui suivent le standard d’autonomie opérationnelle sans être comptées parmi les microservices métier.

Cible confirmée actuelle :

- `YD-PLT-AI-001` AI Gateway
- `YD-PLT-MLP-001` Model Lifecycle & Registry
- `YD-PLT-API-001` External API Management
- `YD-PLT-AUD-001` Audit & Trace

BRENDOLYS Identity reste une plateforme externe à YDIASE et n’est pas documentée ici comme composant possédé par YDIASE.
